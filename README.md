# Pomodoro Timer 🍅

Адаптивный Pomodoro-таймер на React и TypeScript с автоматическим переключением рабочих интервалов и перерывов, анимированным персонажем и звуковыми уведомлениями.

Проект создан как самостоятельный frontend pet-project с акцентом на понятную архитектуру, предсказуемое управление состоянием и доступный интерфейс.

## Возможности

- рабочий интервал — 25 минут;
- короткий перерыв — 5 минут;
- длинный перерыв — 20 минут после четвёртого Pomodoro;
- автоматическое переключение между работой и перерывами;
- Pause, Continue и Restart;
- отображение количества завершённых Pomodoro;
- устойчивый к задержкам `setInterval` расчёт времени через `Date.now()`;
- анимированная SVG-помидорка с разными выражениями для работы и отдыха;
- звуковой сигнал через Web Audio API;
- responsive-интерфейс для desktop и мобильных устройств;
- клавиатурное управление и поддержка `prefers-reduced-motion`.

## Как устроен таймер

Состояние таймера представлено как небольшая state machine:

```text
idle
  ↓ Start
work + running
  ↓ Complete
shortBreak + running
  ↓ Complete
work + running
```

После четвёртого завершённого рабочего интервала запускается `longBreak`. После длинного перерыва счётчик Pomodoro сбрасывается и начинается новый цикл.

`timerReducer` отвечает только за переходы состояния и остаётся чистой функцией. Работа с реальным временем, interval и звуком находится в `useTimer`.

Оставшееся время не уменьшается механически на одну секунду. Hook хранит запланированный момент окончания в `useRef` и вычисляет остаток через `Date.now()`. Благодаря этому задержки interval и работа фоновой вкладки меньше влияют на точность таймера.

### Основные модули

| Файл                                 | Назначение                                                           |
| ------------------------------------ | -------------------------------------------------------------------- |
| `src/hooks/useTimer.ts`              | Связывает reducer с реальным временем и пользовательскими действиями |
| `src/utils/timerReducer.ts`          | Управляет переходами между состояниями таймера                       |
| `src/utils/playChime.ts`             | Создаёт короткий звуковой сигнал через Web Audio API                 |

| `src/types/timer.ts`                 | Содержит TypeScript-типы состояния и действий                        |

## Запуск проекта

После клонирования репозитория установите зависимости:

```bash
npm install
```

Запустите development-сервер:

```bash
npm run dev
```

Vite выведет локальный адрес приложения в терминале.

## Accessibility

- интерфейс доступен для управления клавиатурой;
- основная кнопка сохраняет фокус при Start, Pause и Continue;
- после Restart фокус возвращается на Start;
- режимы обозначаются текстом, а не только цветом;
- семантические HTML-элементы помогают screen reader ориентироваться на странице;
- смена режима объявляется через `aria-live`, но отсчёт не озвучивается каждую секунду;
- декоративный SVG скрыт от screen reader;
- при включённом `prefers-reduced-motion` анимации отключаются.
